The palette

Dracula's hues on a darker ground. Green, cyan and yellow are pulled back a notch so they don't glow, and comments sit dim enough to read past. Click a color to copy it.

In the terminal

Ghostty and Zed's terminal share the same sixteen ANSI colors. Herdr, Claude Code, btop, lazygit and OpenCode follow the same palette.

❯ ~/Projects/draculinho main ✱
❯ sh install.sh ghostty zed btop
copied to ~/.config/ghostty/themes/
✓ zed ✓ btop ✗ chrome (load it unpacked)

One palette, every app

The install script copies each theme into place and points the app's config at it. Run it with no arguments for a menu, name the apps you want, or pass all.

$ curl -fsSL https://raw.githubusercontent.com/eduardoborges/draculinho/main/install.sh | sh
