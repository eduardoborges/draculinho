Pick your apps

      
Select the apps you use and copy one command. The script copies each theme into place and points the app's config at it.

      

      

        $curl -fsSL https://raw.githubusercontent.com/eduardoborges/draculinho/main/install.sh | sh
        
      

      

        
        
With nothing selected, the script opens a menu. It prints the next step for each app, like reloading Ghostty.

      

      
VS Code, Cursor and VSCodium can also install Draculinho from the extensions panel.
